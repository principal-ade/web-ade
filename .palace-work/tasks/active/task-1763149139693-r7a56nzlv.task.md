# Request for New Props

## Request for New Props

The `MarkdownPanel` component currently doesn't expose props to control its internal state. We need the following enhancements:

### Requested Props

1. **`defaultViewMode`** - Allow setting the default view mode
   - Type: `'document' | 'slides'`
   - Default: `'document'`
   - Use case: Start in slides mode instead of document mode

2. **`defaultTocOpen`** - Control whether table of contents is open by default
   - Type: `boolean`
   - Default: `false` (or current default)
   - Use case: Show TOC automatically when panel loads

### Current Limitation

The panel only accepts standard `PanelComponentProps` (context, actions, events) with no way to customize the initial UI state.

### Proposed Interface

```typescript
export interface MarkdownPanelProps extends PanelComponentProps {
  defaultViewMode?: 'document' | 'slides';
  defaultTocOpen?: boolean;
}
```

### Benefits

- Better user experience customization per implementation
- Backwards compatible (optional props with defaults)
- Follows React best practices for controlled/uncontrolled components
