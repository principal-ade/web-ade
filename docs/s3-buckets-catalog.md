## Bucket 1: `feed-collections`

**Environment Variables:**
- `FEED_COLLECTIONS_S3_BUCKET` (default: `feed-collections`)
- `FEED_COLLECTIONS_AWS_REGION` (default: `us-east-1`)

**Shared By:** 2 modules
- Starred Collections
- Feed Collections

### Prefixes & Data Types

#### `starred-collections/`
- **Module:** Starred Collections
- **File:** `src/lib/starred-collections/s3-storage.ts`
- **Purpose:** User-created collections of starred GitHub repos
- **Key Structure:**
  ```
  starred-collections/{user-id}/collections.json
  starred-collections/{user-id}/metadata-cache.json
  ```
- **Data Format:** JSON
- **Features:**
  - ETag-based optimistic locking
  - Versioning (`version` field increments)
  - GitHub metadata caching (repos, users)
- **Criticality:** ⚠️ High - User data, mutations
- **Cache Control:** `max-age=60` (1 minute)

#### `collections/`
- **Module:** Feed Collections
- **File:** `src/lib/feed-collections/s3-storage.ts`
- **Purpose:** Feed collection definitions
- **Key Structure:**
  ```
  collections/{collection-id}.json
  ```
- **Data Format:** JSON
- **Criticality:** ⚠️ High - User data
- **Cache Control:** `max-age=60`

#### `users/`
- **Module:** Feed Collections
- **File:** `src/lib/feed-collections/s3-storage.ts`
- **Purpose:** User feed profiles with subscriptions
- **Key Structure:**
  ```
  users/{github-user-id}.json
  ```
- **Data Format:** JSON
- **Criticality:** ⚠️ High - User data
- **Cache Control:** `max-age=60`

#### `commit-feed/`
- **Module:** Feed Collections
- **File:** `src/lib/feed-collections/s3-storage.ts`
- **Purpose:** User's commit feed state (passed commits, saved cards)
- **Key Structure:**
  ```
  commit-feed/{github-user-id}.json
  ```
- **Data Format:** JSON
- **Criticality:** ⚠️ Medium - User state, can be rebuilt
- **Cache Control:** `max-age=60`

## Bucket 2: `repo-tour-audio`

**Environment Variables:**
- `TTS_S3_BUCKET` (default: `repo-tour-audio`)
- `TTS_AWS_REGION` (default: `us-east-1`)
- `CDN_DOMAIN` (optional - for CloudFront URLs)

**Shared By:** 4 modules
- Line Counts Cache
- GitHub Tree Cache
- File City Cache
- TTS Audio Cache

**Note:** This is a CACHE bucket - all data can be regenerated

### Prefixes & Data Types

#### `line-counts/`
- **Module:** Line Counts Cache
- **File:** `src/lib/line-counts/s3-cache.ts`
- **Purpose:** Cache of line count data per repository
- **Key Structure:**
  ```
  line-counts/{owner}/{repo}.json
  ```
- **Data Format:** JSON
- **Generated By:** Electron app OR web-ADE (repos < 2000 files)
- **Criticality:** ⚡ Low - Cache, can regenerate
- **Cache Control:** `public, max-age=86400` (24 hours)

#### `github-trees/`
- **Module:** GitHub Tree Cache
- **File:** `src/lib/github-tree-s3-cache.ts`
- **Purpose:** Cache of GitHub tree API responses (immutable by SHA)
- **Key Structure:**
  ```
  github-trees/{owner}/{repo}/{sha}.json
  ```
- **Data Format:** JSON
- **Immutable:** Yes (SHA-based)
- **Criticality:** ⚡ Low - Cache
- **Cache Control:** `public, max-age=604800` (7 days)
- **TTL:** Effectively immutable (SHA never changes)

#### `file-city/`
- **Module:** File City Cache
- **File:** `src/lib/file-city/s3-cache.ts`
- **Purpose:** Cache of generated File City visualization PNGs
- **Key Structure:**
  ```
  file-city/{owner}/{repo}/{width}x{height}.png
  ```
- **Data Format:** Binary (PNG image)
- **Criticality:** ⚡ Low - Cache, can regenerate
- **Cache Control:** `public, max-age=31536000` (1 year)

#### Root (TTS Audio)
- **Module:** TTS Audio Cache
- **File:** `src/lib/tts/s3-cache.ts`
- **Purpose:** Cache of TTS-generated audio files
- **Key Structure:**
  ```
  {content-hash}.mp3      (new format)
  {commit-sha}.mp3        (legacy format)
  ```
- **Data Format:** Binary (MP3 audio)
- **Legacy Fallback:** Yes - checks commit-based key first
- **Criticality:** ⚡ Low - Cache, can regenerate
- **Cache Control:** `public, max-age=31536000` (1 year)
- **Special:** Has fallback logic for backward compatibility

## Bucket 3: `principal-view-data`

**Environment Variables:**
- `VERSION_REGISTRY_S3_BUCKET` (default: `principal-view-data`)
- `VERSION_REGISTRY_AWS_REGION` (default: `us-east-1`)

**Shared By:** 1 module
- Version Registry

### Prefixes & Data Types

#### `version-registry/`
- **Module:** Version Registry
- **File:** `src/lib/version-registry/s3-storage.ts`
- **Purpose:** Version-to-commit mappings for deployed services
- **Key Structure:**
  ```
  version-registry/{owner}/{repo}/{serviceName}/{version}/{environment}.json
  ```
- **Data Format:** JSON
- **Example:**
  ```
  version-registry/acme/backend/auth-service/v1.2.3/production.json
  ```
- **Criticality:** ⚠️ High - Registry data for version lookups
- **Cache Control:** `max-age=31536000` (1 year - immutable)
- **Immutable:** Yes - versions are never changed
- **OpenTelemetry:** Instrumented with span events

#### `schematics/`
- **Module:** Version Registry
- **File:** `src/lib/version-registry/s3-storage.ts`
- **Purpose:** Repository schematics (library metadata) by commit SHA
- **Key Structure:**
  ```
  schematics/{owner}/{repo}/{commit-sha}/schematic.json
  ```
- **Data Format:** JSON
- **Example:**
  ```
  schematics/acme/backend/a1b2c3d4e5f6/schematic.json
  ```
- **Criticality:** ⚠️ Medium - Used for version lookups
- **Cache Control:** `max-age=31536000` (1 year - immutable)
- **Immutable:** Yes - commit SHA never changes
- **Shared:** Multiple versions can point to same schematic
- **OpenTelemetry:** Instrumented with span events

## Key Insights

### Shared Bucket Considerations

**`feed-collections` bucket** is shared by:
- Starred Collections (prefix: `starred-collections/`)
- Feed Collections (prefixes: `collections/`, `users/`, `commit-feed/`)

**`repo-tour-audio` bucket** is shared by:
- Line Counts (prefix: `line-counts/`)
- GitHub Trees (prefix: `github-trees/`)
- File City (prefix: `file-city/`)
- TTS Audio (no prefix, root level)

⚠️ **Important:** When migrating, ensure prefix handling is correct to avoid conflicts!

### Immutable vs Mutable Data

**Immutable (set once, never changes):**
- GitHub Tree Cache (SHA-based)
- Version Registry registrations (version immutable)
- Version Registry schematics (commit SHA immutable)

**Mutable (can be updated):**
- Starred Collections (user edits collections)
- Feed Collections (user creates/modifies)
- User profiles (subscriptions change)
- Commit feed state (user interaction)

**Cache (regenerable):**
- Line Counts (can recompute)
- File City images (can regenerate)
- TTS audio (can regenerate)

## Testing Considerations

### Critical Test Cases

1. **ETag Conflicts (Starred Collections)**
   - Concurrent updates
   - Retry logic
   - Max retries exceeded

2. **Binary Data (File City, TTS)**
   - Buffer handling
   - Content-Type headers
   - URL generation

3. **Legacy Fallback (TTS)**
   - Old key format still works
   - New key format preferred
   - Migration path tested

4. **LIST Operations (Feed Collections, Version Registry)**
   - Pagination handling
   - Filtering by prefix
   - Performance with many objects

5. **OTEL Instrumentation (Version Registry)**
   - Span events emitted
   - Attributes correct
   - No span leaks
